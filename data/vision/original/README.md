# Original research inputs

The release includes the publisher’s two unchanged CSV input tables used in the lighting experiment and the unchanged openly licensed handwriting recording used in the archived gesture-recognition experiment.

| Distributed file | Original work and attribution | License |
| --- | --- | --- |
| lux-features.csv | Anton Buryi, *A Controlled Smartphone Image Dataset for AI-Based Workplace Illuminance Estimation*, feature_master_latest.csv, revision 3. [Dataset](https://doi.org/10.5281/zenodo.20657011) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| lux-annotations.csv | Anton Buryi, same dataset, annotation_master_latest.csv. [Dataset](https://doi.org/10.5281/zenodo.20657011) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| writing.webm | Peter Unbehauen, *Handwriting Minuscule Alphabet*. [Original video](https://commons.wikimedia.org/wiki/File:Handwriting_Minuscule_Alphabet.webm) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |

The Pexels recordings can be retrieved by exact source URL and verified against SHA-256 in [the gesture manifest](../gesture-recordings.json). ASSISTments has its own [retrieval and data-sharing terms](../../dkt/README.md). Original family worksheet photographs stay in local private storage.
